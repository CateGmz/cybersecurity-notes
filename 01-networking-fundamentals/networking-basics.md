# Networking Basics & Fundamentals

## 1. What is a Computer Network?
A computer network is a collection of interconnected devices (such as computers, servers, switches, and routers) that share resources, exchange data, and communicate with one another using standardized communication protocols.

---

## 2. Core Hardware Components
To understand how data moves, we need to look at the physical and logical building blocks of a network:
* **Host (End Device):** Any device that originates or receives data (e.g., your laptop, a smartphone, or a cloud server).
* **Switch:** Connects devices together within a local network (LAN) and uses MAC addresses to forward data frames to the correct destination port.
* **Router:** Connects different networks together (e.g., connecting your home network to the wider Internet) and uses IP addresses to route packets across optimal paths.

---

## 3. IP Addresses vs. MAC Addresses
In networking, every device needs identifiers to communicate, much like mailing a letter:
* **MAC Address (Media Access Control):** A hardcoded, permanent physical address burned into the network interface card (NIC) by the manufacturer. It is used for local delivery within the same room or local network (LAN).
* **IP Address (Internet Protocol):** A logical, configurable address assigned to a device by a network (via DHCP). It is used for routing traffic across different networks globally (WAN/Internet).

> 💡 **Analogia da Carta Postal:** 
> Pensa no **MAC Address** como o **nome completo da pessoa** dentro de uma sala de escritórios (só serve para identificar quem está ali perto). Pensa no **IP Address** como a **morada completa (País, Cidade, Rua, Número de Porta)** que o carteiro precisa de saber para entregar uma carta do outro lado do mundo.

---

## 4. Summary & Key Takeaways
* Networks connect devices to share information efficiently.
* Switches handle local traffic using physical addresses (MAC), while routers handle global traffic using logical addresses (IP).
* Understanding this distinction is the first foundational step in mastering networking and cybersecurity.
